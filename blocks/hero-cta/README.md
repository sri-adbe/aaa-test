# hero-cta

Custom **hero** block for the `lux` page template. Purpose: end-of-page conversion band on lux template pages.

## Authoring (Document Authoring)

Model: `standalone`

Row 1: background image. Row 2: eyebrow paragraph, H2, bold CTA link, note paragraph.

Styled by the `lux` template (`Template: lux` in page metadata), which supplies the fonts and `--lux-*` tokens.

## Supported variations

No variations.
