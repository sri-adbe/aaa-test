# cards-service

Custom **cards** block for the `lux` page template. Purpose: service / offering highlights.

## Authoring (Document Authoring)

Model: `standalone`

Repeating rows; each row = one cell with H3 + description (optional authored number paragraph).

Styled by the `lux` template (`Template: lux` in page metadata), which supplies the fonts and `--lux-*` tokens.

## Supported variations

No variations.
