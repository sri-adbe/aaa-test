# cards-curator

Custom **cards** block for the `lux` page template. Purpose: travel curator / advisor introductions.

## Authoring (Document Authoring)

Model: `standalone`

Repeating rows; each row = image cell + body cell (eyebrow paragraph, H3, bio paragraph, link paragraph).

Styled by the `lux` template (`Template: lux` in page metadata), which supplies the fonts and `--lux-*` tokens.

## Supported variations

No variations.
